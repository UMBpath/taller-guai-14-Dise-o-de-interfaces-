10 Opciones con Hosting Gratuito

Una infografía individual para cada herramienta, explicando qué permite hacer en su plan gratuito, sus límites y para qué tipo de proyecto conviene.

#01 Frontend

Vercel

La mejor opción si trabajas con Next.js o React. Te da 100 GB al mes de transferencia y despliega automáticamente cada vez que haces push a GitHub.

⬇
#02 JAMstack

Netlify

Muy práctica para sitios que tienen formularios de contacto porque los captura sin tener que programar un backend. Incluye 100 GB/mes.

⬇
#03 Estático

GitHub Pages

El clásico para proyectos escolares y portafolios. Se activa con un clic en tu repositorio público de GitHub y es 100% gratuito sin caducidad.

⬇
#04 Fullstack

Render

Ideal cuando necesitas correr un backend en Node.js, Python o un contenedor Docker. También aloja páginas estáticas gratis de forma ilimitada.

⬇
#05 Edge CDN

Cloudflare Pages

De las pocas plataformas que no te cobran por ancho de banda en su plan sin costo. Los servidores responden rápido en cualquier parte del mundo.

⬇
#06 Google Cloud

Firebase Hosting

La plataforma de Google. Da 10 GB de almacenamiento y se conecta directo con autenticación de usuarios (login) y bases de datos en tiempo real.

⬇
#07 Base de Datos

Supabase

Alternativa de código abierto a Firebase. Te da una base de datos PostgreSQL de 500 MB y baldes de 1 GB para almacenar fotos o documentos.

⬇
#08 Contenedores

Railway

Detecta automáticamente el lenguaje de tu código sin configurar servidores. Soporta Docker y levanta bases de datos MySQL, Mongo o Redis en segundos.

⬇
#09 MicroVMs

Fly.io

Ejecuta microservidores físicos cerca de los usuarios. Permite hasta 3 máquinas virtuales pequeñas y 3 GB de disco persistente sin pagar.

⬇
#10 CLI Express

Surge.sh

La herramienta más rápida para entregar tareas: abres la terminal, escribes un comando y en 3 segundos la página web ya está disponible en internet.
